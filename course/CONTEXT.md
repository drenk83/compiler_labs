# Курсовая: распознаватель bash-cw

Распознаватель учебного подмножества синтаксиса bash.

## Language

**Распознаватель**:
Программа, которая читает файл `.sh` и решает, принадлежит ли текст входному языку.
_Avoid_: компилятор, интерпретатор, диалект-детектор

**Входной язык**:
Множество текстов, которые принимает грамматика распознавателя. Имя в документах: bash-cw. Это не отдельный шелл и не семейство диалектов bash/dash/zsh.
_Avoid_: диалект, «bash» без уточнения

**Принятие**:
Вход принадлежит входному языку. Распознаватель ничего не печатает.
_Avoid_: OK, success, «correct»

**Ошибка**:
Вход не принадлежит входному языку. Распознаватель сообщает номер строки.
_Avoid_: warning, unsupported
